# MacroVision Web MVP v0.8 Route/API Map

This map covers the nine planned Persian MVP routes. All API paths are existing
MacroVision v0.7.0 contracts unless the row explicitly identifies a gap. Public
availability in this document means product intent, not current authorization: the
existing API has no authentication and must remain on a trusted private network.

## Shared contract notes

- Phase 2A dashboard codes are exactly `home`, `markets`, and `macro`; definitions use
  stable raw series codes and derived definition codes, never database IDs.
- Phase 2B initial page reads run server-side with `cache: "no-store"` and a bounded
  timeout. Browser calls retain the same-origin boundary and never receive the private
  backend URL.
- Each connected page performs two parallel dashboard reads plus at most one bounded
  featured-series read. It never fans out one request per metric.
- Metric identity is unique across the complete dashboard. Definition and summary
  membership is validated per `group_code`, and rendering uses a composite
  group/metric lookup so no metric can be silently overwritten or moved.
- Featured charts preserve API ordering and missing gaps, request at most 200 persisted
  points, and use exact Decimal strings for labels, tooltips, and accessible tables.
- Derived featured charts are pinned to the exact summary `run_id` through
  `/api/v1/analytics-runs/{run_id}/observations`; returned run, definition, and version
  identities must all match.
- Only a chart-local adapter projects exact strings to finite numeric coordinates for
  approximate canvas geometry. Empty, all-missing, identity-mismatch, endpoint-error,
  and runtime-error states remain distinct, while displayed evidence stays exact.
- ECharts consumes the shared CSS tokens and observes both forced-light and system
  color-scheme changes. This does not add browser financial calculation.
- Missing configured data is returned explicitly with a metric state. It is not omitted,
  and no write, provider synchronization, or Analytics execution occurs during a GET.
- List endpoints use deterministic `limit`/`offset` pagination, with `limit` bounded to
  1–200.
- Raw Macro Data values are exact eight-decimal JSON strings.
- Analytics Decimal outputs are canonical JSON strings.
- Summary metrics carry value and point identity, comparison type/period/anchor,
  reference value, backend-computed absolute/percentage change, observation and
  knowledge cutoffs, freshness, source, and derived run/version where applicable.
- Metric state describes the selected point only; comparison state independently
  describes comparison completeness and never hides a present current value.
- `basis_code` is the stable comparison-period code. `anchor_policy` is
  `not_applicable`, `previous_observation`, or `same_observed_at`. Existing derived
  comparisons require exact UTC-normalized observation timestamps; no nearby-period
  alignment, interpolation, resampling, filling, or shifting is performed.
- Raw metrics use `raw_series_stale_after_days`. Derived metrics currently use
  `not_configured`; no raw threshold is borrowed and no threshold is invented.
- `stale_metric_count` counts metrics with `freshness.status == stale`, regardless of
  whether their comparison is available, missing, incomparable, or frequency-mismatched.
- Non-representable absolute or percentage changes remain exact-point responses with an
  `incomparable` comparison and null non-representable outputs; they never become
  Infinity, NaN, float values, or whole-summary failures.
- The browser never computes MoM, YoY, difference, spread, ratio, or z-score values.
- UTC is canonical; Persian localization is display-only.
- Localized labels never override canonical code, unit, frequency, geography, or source.
- `is_active` never implies reviewed publication eligibility.
- Browser calls use same-origin `/api/v1/*`; the transparent proxy preserves FastAPI
  paths, status codes, query parameters, safe errors, and Decimal strings.
- Current and historical as-of modes must never share an ambiguous visual state.
- GET routes read persisted state and never execute Analytics implicitly.
- Ratio, spread, and other transformations use the explicit Analytics run API.
- Mutation routes are private until secure sessions, CSRF, authorization, and rate
  limiting are implemented.
