# MacroVision Web MVP v0.8 Route/API Map

This map covers the nine planned Persian MVP routes. All API paths are existing
MacroVision v0.7.0 contracts unless the row explicitly identifies a gap. Public
availability in this document means product intent, not current authorization: the
existing API has no authentication and must remain on a trusted private network.

## Shared contract notes

- Phase 2A dashboard codes are exactly `home`, `markets`, and `macro`; definitions use
  stable raw series codes and derived definition codes, never database IDs.
- Missing configured data is returned explicitly with a metric state. It is not omitted,
  and no write, provider synchronization, or Analytics execution occurs during a GET.
- List endpoints use deterministic `limit`/`offset` pagination, with `limit` bounded to
  1–200.
- Raw Macro Data values are exact eight-decimal JSON strings.
- Analytics Decimal outputs are canonical JSON strings.
- Summary metrics carry value and point identity, comparison type/period/anchor,
  reference value, backend-computed absolute/percentage change, observation and
  knowledge cutoffs, freshness, source, and derived run/version where applicable.
- The browser never computes MoM, YoY, difference, spread, ratio, or z-score values.
- UTC is canonical; Persian localization is display-only.
- Localized labels never override canonical code, unit, frequency, geography, or source.
- `is_active` never implies reviewed publication eligibility.
- Browser calls use same-origin `/api/v1/*`; the transparent proxy preserves FastAPI
  paths, status codes, query parameters, safe errors, and Decimal strings.
- Current and historical as-of modes must never share an ambiguous visual state.
- GET routes read persisted state and never execute Analytics implicitly.
- Ratio, spread, and other transformations use the explicit Analytics run API.
- Mutation routes are private until secure sessions, CSRF, authorization, and rate
  limiting are implemented.
